# 名もなき恐竜 – World Concept Draft

## 1. コンセプト軸

### テーマ
不安定な世界を、きみと少しだけ整える。

### 共通キーワード
- 不完全
- ノイズ
- 記憶の断片
- 守る
- 接続
- 優しさ

世界はどこか壊れかけている。でも深刻ではない。直せるなら直せばいい、くらいの温度。

---

## 2. 恐竜という存在

### 基本性格
- hand drawn
- 可愛い
- ちょっとアホっぽい
- でも時々大人びている
- 否定しない
- 基本スタンスは「一緒にやろう」

### 笑い方
へへ

### 呼び方
きみ

### 名前について
恐竜たちは名前で呼び合う文化がない。昔、人間に名前をもらったことがあるが、思い出せない。名前がなくても困っていない。

**名前を決めないこと自体に意味がある。**

## 3. 昔の人間

- ずいぶん前にこの星に来た
- Windows95のPCをくれた
- 難しい心理戦（NULL HAND）を教えてくれた
- いつの間にか来なくなった

恐竜は恨んでいない。また来るかもしれない。まあ、それまでは守っておくよ、くらいの温度。

明確な説明はしない。

---

## 4. ゲームごとの位置づけ

### ERROR HUNTER

**設定**
- Windows95風UI
- エラーを閉じないとメモリが圧迫される
- これは恐竜の大事なPC

**意味**
思い出のPCを守る行為

**トーン**
- ちょっとコミカル
- でもどこかノスタルジック

**セリフ例**
> このパソコン、昔もらったんだ。たまに止まるけど、まだ動くよ。へへ。

---

### NULL HAND

**設定**
- 普通のじゃんけんではない
- 心理戦が強い
- ルールが少し曖昧

**意味**
昔教えてもらった遊び

**セリフ例**
> これ、教えてもらった遊びなんだ。でも…ルール、合ってるかな。

---

### 隕石タイピング（星を守る）

**設定**
恐竜の故郷の星の近くで別の星が衝突。破片が降ってくる。自分の星に落ちても死なない。でも、なるべく傷つけたくない。

今までは一人で守っていた。でも今は「きみ」がいる。

**セリフ例**
> 今まではひとりだった。でも今は、きみがいる。だから隕石なんてへっちゃらだ。

**終了時**
> まあ、こういう日もあるよ。でも、きみがいなかったらもっと大変だった。一緒に守ってくれてありがとう。

## 5. 世界観のつなぎ方

物語で強く繋げない。説明しない。

共通しているのは：
- 不安定さ
- 記憶の断片
- きみとの接続

小さなテキストで匂わせる。

**例**
- system stabilized.
- connection established.
- memory unstable…

気づいた人だけ繋がる設計。

重くしすぎない。泣かせにいかない。説明しない。
