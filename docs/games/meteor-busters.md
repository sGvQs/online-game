# Meteor Busters ゲーム仕様書

## 1. 概要

「Meteor Busters」は、Star Shield の世界観をベースにした協力型シューティングゲームです。
1〜3人のプレイヤーが俯瞰視点で協力して隕石を撃破し、最終的な破壊率を記録します。

---

## 2. 視点・画面構成

- **視点**: 俯瞰（ホームタイトルと同じ目線・軌道ロジック流用）
- **中心**: スターシールドの星
- **軌道計算**: ホーム画面の軌道・遠近感・スケーリングをそのまま流用

---

## 3. ゲームの目的

星の軌道上に出現する隕石を撃破する。
撃破できなかった隕石は星と衝突する（HPではなく**破壊率**として記録）。

---

## 4. 隕石の動き

```
右上（出現・小）
    ↓
中央（最大サイズ・危険ゾーン）
    ↓
左下（画面外へ）
    ↓ 軌道を継続
左下 → 右上方向へ折り返し
    ↓
星の裏側に差し掛かる ← ここで衝突判定（ミス確定）
```

- 隕石は星を軌道する形で移動する
- **隕石ごとにY方向のオフセットがある**（同一軌道にならないばらつき）
- ばらつきは中央通過時点で ±20〜30px 程度
- 同時出現なし（1体ずつ順番にスポーン）

---

## 5. 弾システム

### 弾の種類

| 弾 | 対応隕石 | 一致時ダメージ | 不一致時ダメージ |
|----|----------|---------------|-----------------|
| 弾A | 隕石A | 25 | 1 |
| 弾B | 隕石B | 25 | 1 |
| 弾C | 隕石C | 25 | 1 |

- 弾と隕石は**グロー影（drop-shadow）の色**で3種類を区別
  - タイプA: 赤 `drop-shadow(0 0 8px red)`
  - タイプB: 青 `drop-shadow(0 0 8px blue)`
  - タイプC: 黄 `drop-shadow(0 0 8px yellow)`
- 隕石・弾の形状は同一、影色のみで判別
- 回復効果なし（不一致は単純に1ダメージ）

### 隕石HP

| 難易度 | 隕石HP |
|--------|--------|
| 易しい | 75 |
| 普通 | 100 |
| 難しい | 150 |

### リロード

- 弾数上限: **12発**（仮）
- **スペースキー**を押すと `reload.se` が鳴り、12発に補充される
- 表示・HUDはホーム画面と同じイメージ（ドットバー＋色）

---

## 6. 操作

| 操作 | アクション |
|------|-----------|
| クリック | 弾の切り替え（A→B→C→A…） |
| スペース | リロード |
| スペース以外の任意キー | 射撃 |

- クリックは**切り替えのみ**（射撃しない）

---

## 7. プレイ人数と難易度

**人数と難易度は独立した軸**。人数に関わらず難易度を選択できる。

### 人数によるゲーム感の変化（設計上の意図）

| 人数 | 特徴 |
|------|------|
| 1人 | 弾を切り替えながら複数隕石を捌く → 認知負荷が集中 |
| 2人 | 別種の弾を同時に撃てる → カバー範囲が広がる |
| 3人 | 自然と「各自が得意な弾を担当」する動きになる → 混乱しにくい |

役割を強制しないのに、人数が増えると自然に楽になる設計。

---

## 8. クリア・終了条件

- **スポーン数**: 難易度ごとに固定（時間制限なし、同時出現なし）
- **終了タイミング**: 全隕石が出し切られたら数秒後にゲーム終了
- **クリアライン**: 破壊率 **80%** 以上でクリア

### 難易度パラメータ（仮）

| 難易度 | スポーン数 | スポーン間隔 | 隕石HP |
|--------|-----------|------------|--------|
| 易しい | 15体 | 4秒 | 75 |
| 普通 | 20体 | 3秒 | 100 |
| 難しい | 30体 | 2秒 | 150 |

### ポイント

| 難易度 | クリア時獲得ポイント |
|--------|-------------------|
| 易しい | +3 pt |
| 普通 | +5 pt |
| 難しい | +8 pt |

- 協力型のため全員が同額獲得

## 9. マルチプレイヤー設計

### 責務分担

| 責務 | 担当 |
|------|------|
| 隕石スポーン・位置管理 | ホスト |
| 隕石HP・ダメージ計算 | ホスト |
| 破壊率集計 | ホスト |
| カーソル位置 | 各自がbroadcast |
| 弾の切り替え状態 | 各自がローカル管理 |

### broadcastイベント

```ts
// 射撃イベント（ゲスト → ホスト）
{ type: 'SHOT', playerId, bulletType: 'A' | 'B' | 'C', originX, originY, meteorId }

// カーソル位置（各自 → 全員、50msごと）
{ type: 'CURSOR', playerId, x, y, bulletType }

// 隕石状態更新（ホスト → 全員）
{ type: 'METEOR_UPDATE', meteorId, hp }

// 隕石ミス（ホスト → 全員）
{ type: 'METEOR_MISSED', meteorId }

// ゲーム終了（ホスト → 全員）
{ type: 'GAME_END', destroyRate: number }
```

### 体験方針

| 項目 | 方針 |
|------|------|
| 自分の弾 | 即座にアニメ再生（オプティミスティック） |
| 相手の弾 | SHOTイベント受信後にアニメ再生 |
| カーソル | throttle 50ms で描画（相手の弾色も表示） |
| ヒット演出 | ホストの確定後にエフェクト（隕石HP変化） |

### 相互視認

- **お互いのカーソルが見える**（プレイヤーカラーで区別）
- **お互いの現在の弾が見える**（CURSORイベントに bulletType を含める）
- **お互いの発射した弾が見える**（SHOTイベントで originXY → meteorId 方向にアニメ再生）
