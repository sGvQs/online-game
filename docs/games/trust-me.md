# TRUST ME

## 概要

自分の頭のシンボルだけが見えない。他のプレイヤーは見える。DMで届く情報を信じるか疑うか——運命はDMの中にある。

プレイヤーの中に潜むジョーカーを、論理と観察で見つけ出す情報戦ゲーム。

---

## 基本情報

| 項目 | 内容 |
|---|---|
| プレイ人数 | 5〜8人 |
| シンボル | ○ / △ / × の3択 |
| 役職 | 通常プレイヤー + ジョーカー1人 |

各プレイヤーの頭には3種のシンボルのどれかが割り当てられる。自分のシンボルは自分には見えないが、他の全プレイヤーには見える。

---

## 勝利条件

- **プレイヤー陣営**: ジョーカーを脱落させる
- **ジョーカー**: 1対1の状況に持ち込む（残り2人になった時点でジョーカーの勝ち）

---

## フェーズ構成（毎ターン繰り返し）

```
会話フェーズ
    ↓
ジョーカー技フェーズ
    ↓
DMフェーズ
    ↓
ジャッジフェーズ
    ↓
（5ターンごと）強制脱落
```

### 会話フェーズ
全員が自由に話せる。他のプレイヤーのシンボルを共有したり、同盟を組んだり、疑いをかけたりする。ジョーカーもここに参加する。時間制限あり（人数に応じて60〜120秒）。

### ジョーカー技フェーズ
ジョーカーのみがスキルを使用できる。使用したかどうかは他のプレイヤーには一切わからない。

### DMフェーズ
全員が任意の1人に対して**50文字以内のフリーテキスト**でDMを送る。内容は送り主と受け取り主だけが知る。

- シンボル情報を伝える、同盟を結ぶ、疑いを伝えるなど内容は自由
- 1ターンに1通のみ、必ず送らなければならない
- **時間制限なし**。じっくり考えて送ること
- **会話禁止**。このフェーズ中は発言できない
- 全員が送信完了した時点で次フェーズへ自動進行

### ジャッジフェーズ
全員が**同時に**自分のシンボルを宣言する。

- ○ / △ / × の中から必ず1つ宣言（回避不可）
- 間違えた場合は**即座に脱落**

### 強制脱落（5ターンごと、ジャッジフェーズ後）
5ターンを経過するたびに、ジョーカーは任意の1人を脱落させることができる。脱落した様子は通常のジャッジミスと区別がつかない。このルールはゲーム開始前に全員に周知されるが、実際に使用されたかどうかは誰にもわからない。

---

## ジョーカーのスキル

スキルはそれぞれ**1ゲームに1回のみ**使用可能。ジョーカー技フェーズに任意のターンで発動できる。

| スキル | 効果 |
|---|---|
| 盗聴 | そのターンの全DMの内容を傍受する（DMフェーズ後・ジャッジフェーズ前に解決） |
| 共犯者 | 任意の1人を共犯者にする。共犯者がDMを送った相手がジャッジフェーズで脱落しなかった場合、共犯者が即座に脱落する |
| スワップ | 任意の2人のシンボルを入れ替える（自分自身を含めることができる） |
| なりすまし | 任意の1人のDMを乗っ取り、偽の内容に差し替える（元のDMは無効化） |

ゲーム開始時、上記4種からランダムで付与される。8人の場合は全スキルが使用可能。

### スキルの補足

**盗聴**
全DMを見ることで同盟関係や情報の流れを把握できる。次のターンで最適な行動を取れる。口が苦手なジョーカーでも情報優位で動ける。

**共犯者**
共犯者になったプレイヤーは自分がその役割を担わされたことをDMフェーズで知る。共犯者が誰かは他のプレイヤーには分からない。DMの内容は自由だが、送った相手が正しく生き残った場合は自分が脱落するため、嘘をつくことが自己保身に直結する。真実を教えることも可能だが、それは自分の脱落を意味する。

**スワップ**
自分を含めてスワップすると自分のシンボルが確実にわかるため、自己保身にも使える。会話フェーズ後・DMフェーズ前に発動するため、会話で共有された情報とDMの情報が食い違う。

**なりすまし**
元の送り主のDMは無効化され、ジョーカーの偽DMのみが届く。送り主が疑われるフレームアップに使える。

---

## 重要なゲームメカニクス

### プレイヤーがジョーカーを倒す方法
人狼のように「告発して多数決で排除」するのではなく、**ジョーカーに偽の情報をDMで送り、ジャッジで誤った宣言をさせる**ことで脱落させる。

### 偽DMのリスク
疑ったプレイヤーに偽のシンボル情報を送り、そのプレイヤーが正しく宣言した場合、偽DMを送った自分の信頼性が大きく失われる。積極的に動くことと、信頼を保つことのバランスが問われる。

### スキルの不確実性
全スキルが「ルールには明記されているが使用されたかどうかわからない」設計になっている。脱落が起きるたびに「本当に外したのか？ジョーカーのスキルか？」という疑念が続く。

### 脱落後の観戦
脱落したプレイヤーはゲームの続きを観戦できる。脱落した瞬間にジョーカーの正体・スキル使用履歴・全DMが見えるようになり、ゲームの全貌を俯瞰できる。

---

## 設計思想

- **論理×心理×情報戦**: 口が上手い人が有利な演技ゲームではなく、論理的な観察力と情報分析が武器になる
- **非ライアーフレンドリー**: ジョーカーは機械的なスキルで戦えるため、嘘をつくのが苦手な人でも勝てる
- **行動が全て証拠になる**: 発言・DM・スキル使用のタイミングが全て推理の材料になる

|---|---|---|
| 5人 | 1（ランダム） | 心理戦・情報戦。スキルが何かの読み合いも発生 |

### RLS方針まとめ

```
通常プレイヤー（生存中）
  ・自分のsymbol: 読めない
  ・他人のsymbol: 読める
  ・自分のrole: 読める
  ・他人のrole: 読めない
  ・DM: 自分が送受信したもののみ
  ・skill_uses: 読めない
  ・elimination_type: 読めない

ジョーカー（生存中）
  ・上記に加えて
  ・自分のskills: 読める
  ・skill_uses: 自分のもののみ読める
  ・wiretap使用ターン: 全DMを読める

脱落者（is_alive = false）
  ・全プレイヤーのrole: 読める
  ・全プレイヤーのskills: 読める
  ・is_accomplice: 読める
  ・全DM: 読める（is_interceptedも含む）
  ・全skill_uses: 読める
  ・elimination_type: 読める
```

### フェーズ進行ロジック

HOSTによる進行管理は行わない。全クライアントがDBの状態を監視し、条件を満たしたと検知したクライアントがServer Actionを叩く。Server Action側でDB状態を確認してから進行するため、複数クライアントが同時に叩いても二重進行しない。

```
全クライアントがSupabase Realtimeでmatches tableを購読
  ↓
条件成立を検知したクライアントがadvancePhase()を呼ぶ
  ↓
Server Action:
  IF current_phase = 期待するフェーズ AND 条件を満たしている
  THEN フェーズを進める（atomic update）
  ELSE 何もしない（no-op）
```

| フェーズ | 進行条件 | 次フェーズ |
|---|---|---|
| conversation | phase_deadline < now() | joker_skill |
| joker_skill | ジョーカーがアクション完了 | dm |
| dm | 生存全員のDM送信完了 | judgment |
| judgment | 生存全員の宣言完了 → 脱落処理 → 勝利判定 | conversation（次ターン） |

会話フェーズの時間制限:

| 人数 | 制限時間 |
|---|---|
| 5人 | 60秒 |
| 6〜7人 | 90秒 |
| 8人 | 120秒 |
