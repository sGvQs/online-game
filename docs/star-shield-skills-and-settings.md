# Star Shield スキル・設定画面 仕様

## 1. 管轄の整理

| 管轄 | 役割 | 該当スキル |
|------|------|-----------|
| **Typing管轄** | Typist | 回復（ヒール）、HP（星のHP） |
| **Shooting管轄** | Shooter | 通常攻撃、必殺技 |

---

## 2. 通貨（typing数）

### 定義
- **userId** に紐づく累積値
- **Star Shield のみ**加算（他ゲームは干渉しない）

### 加算タイミング
- 正解1文字打鍵ごとに +1（fire イベント発火分）
- マッチ終了時に fireCount 相当を加算

### 保存
- テーブル: `star_shield_user_progress`
- カラム: `totalTypingCount`

---

## 3. 初期状態（新規ユーザー）

ユーザー登録（`syncUser`）と同時に以下を DB に作成:

| 項目 | 初期値 |
|------|--------|
| StarShieldUserProgress | totalTypingCount: 0, starHpLevel: 1 |
| red（通常攻撃） | level 1 |

---

## 4. Typing管轄スキル

### 4.1 星のHP

- **レベル**: 1〜5（難易度に依存しない）
- **HP値** (`LEVEL_STAR_HP`): lv1=15, lv2=20, lv3=26, lv4=34, lv5=45
- **Typist** が使用する星の最大HP
- ゲーム中、星のHPバーはこの値が上限

**レベル上げコスト** (`STAR_HP_LEVEL_UP_COSTS`):

| レベル | 消費 typing |
|--------|-------------|
| 1→2 | 1,500 |
| 2→3 | 3,500 |
| 3→4 | 7,000 |
| 4→5 | 12,000 |

### 4.2 ヒール

- **発動**: 単語完了時（Typist が打ち切った時）
- **レベル**: 解放〜lv max（1〜6）
- **lv max** で全破壊（all_destruction）を付与

**解放コスト**: 3,000 typing

**レベル上げコスト**:

| レベル | 消費 typing |
|--------|-------------|
| 1→2 | 4,000 |
| 2→3 | 8,000 |
| 3→4 | 15,000 |
| 4→5 | 30,000 |
| 5→max | 100,000 |

**回復量** (`LEVEL_HEAL_RECOVERY`): 実数値で現在HPに加算。最大HPでキャップ。

| レベル | 回復量 |
|--------|--------|
| lv1 | 0.1 |
| lv2 | 0.2 |
| lv3 | 0.4 |
| lv4 | 1.6 |
| lv5 | 1.0（全回復） |
| lv max | 1.0 + 全破壊 |

---

## 5. Shooting管轄スキル

### 5.1 通常攻撃

- **発動**: 1文字打鍵ごと（Typist が打つたび）
- **初期所持**: red のみ（lv1）

| スキルID | 名前 | 解放コスト |
|----------|------|------------|
| red | 赤い球 | 0（初期所持） |
| blue | 青い球 | 1,000 |
| yellow_beam | 黄色いビーム | 3,000 |
| purple | 紫の球 | 500 |
| orange | オレンジの球 | 5,000 |

**レベル**: 技ごとに 1〜5。レベル上げは技ごとに独立したコスト。

### 5.2 必殺技

- **発動**: 単語完了時（ヒールと同じタイミング）
- **1種類**: spread（広範囲弾）
- **レベル**: 1〜10 で規模・弾数を制御
- **all_destruction（全破壊）**: ヒール lv max でのみ獲得（ショップにはない）

**spread 解放コスト**: 20 typing

**レベル上げコスト**: 2→3: 30, 3→4: 60, ... 10: 2,000

---

## 6. スキル設定（loadout）

ゲームで使用するスキルを事前に選択。所持スキルのみ選択可能。

| 項目 | 説明 |
|------|------|
| selectedNormalAttackId | Shooter の通常攻撃（red, blue など） |
| selectedSpecialAttackId | Shooter の必殺技（spread / all_destruction） |
| selectedHealLevel | Typist のヒールレベル（1-6。null=使わない） |

---

## 7. 画面・導線

- **スキル設定画面**: タイトル画面（READY/START がある画面）から「⚙️ スキル設定」リンクで遷移
- **役割選択画面**: スキル設定への導線なし
- **URL**: `/game/[roomId]/star-shield/settings`
