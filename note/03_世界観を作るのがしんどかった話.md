# 世界観を作るのがしんどかった話

---

## 1. 前回の引きを回収します

前回の記事で「後付けで世界観が生えてきた」とさらっと書いたんですが、実はあのあと少し悩みました。正確には「生えてきた世界観に、でかい矛盾があることに気づいた」という話です。

---

## 2. タイトル画面でふつうに星を壊してる

Star Shieldというゲームのタイトル画面では、プレイヤーが宇宙空間でビームを撃ちまくって、星とか惑星とかをどんどん破壊しています。地球みたいなやつも壊します。普通に。

で、本編はというと、恐竜と一緒に隕石から星を守るゲームです。

…あれ、この人、さっき星を壊してませんでしたっけ。

「守る話を書こう」と思っていたのに、タイトル画面の時点でプレイヤーがぶち壊し屋になっていました。自分で作っておいて、気づいたのがだいぶ後です。

## 3. プレイヤーって結局なんなんだ

矛盾に気づいてから、「じゃあプレイヤーって何者なんだ」という問いが止まらなくなりました。

守ってるのに壊してる。壊してるのに守ってる。どっちが本当のこいつなんだ、と。

色々考えた末に出てきたのが、「壊すのも、守るのも、どちらも本当」という設定です。プレイヤーは、別の星系が太陽系に接近しすぎたせいで引き込まれてくる星を壊してきた存在。太陽系を守るために。感情的な理由はなく、ただ必要だからやっていた。

破壊した星の破片は宙域に散らばる。それが隕石になって、引力の強い星に降り注ぐ。

つまり、タイトル画面で壊していた星の破片が、本編で降ってくる隕石かもしれない。ゲームはそれを説明しないけど。

ここまで考えたとき、なんかしっくりきました。壊した側が守る側になる瞬間、みたいなものが出てきた気がして。

---

## 4. 説明しないことにした

世界観がまとまってきたところで、もうひとつ決めたことがあります。「説明しない」ということです。

恐竜がなぜパソコンを持っているのかも、なぜじゃんけんを知っているのかも、ゲーム内では一切説明しません。「誰かの記憶の断片でできた存在かもしれない」という設定はあるけれど、誰の記憶かは今のところわからない。今後のゲームで少しずつ近づくかもしれないし、永遠にわからないままかもしれない。

ゲームの隅に「whose memory is this?」みたいなテキストを置いておいて、気づいた人だけが繋がる、くらいの温度感でいいかなと思っています。

矛盾から始まって、気づいたらそういう設計になっていました。後付けの割には、気に入っています。
